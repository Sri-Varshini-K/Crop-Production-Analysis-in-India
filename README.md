# Crop Production Analysis in India | Excel & Power BI

##  Project Overview
This  project focuses on analyzing agricultural data in India using Microsoft Excel and Power BI. The project involves data cleaning, transformation, data modeling, DAX calculations, and interactive dashboard development to understand crop production, cultivated area, yield, and regional agricultural trends.

## Objectives
- Clean and preprocess agricultural data using Excel.
- Analyze crop production, area, and yield.
- Compare agricultural performance across states, districts, crops, and seasons.
- Create DAX measures and KPIs using Power BI.
- Develop an interactive dashboard to support data-driven decision-making.

## Tools & Technologies
- Microsoft Excel
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Pivot Tables

## Project Workflow

### 1. Data Cleaning and Preprocessing – Excel
- Checked for duplicate records.
- Handled missing Crop Code and Production values.
- Standardized column headings and data formats.
- Created calculated fields using Excel formulas.
- Applied filtering and sorting.
- Created Pivot Tables to summarize agricultural data.

### 2. Data Modeling and DAX – Power BI
- Imported the cleaned agricultural dataset.
- Prepared the data model for agricultural analysis.
- Created DAX measures:
  - **Total Production**
  - **Total Area**
  - **Total Crops**
  - **Total States**
  - **Average Yield**

### 3. Dashboard Development
Developed an interactive Agriculture Data Analysis Dashboard featuring KPI cards, charts, and slicers.

The dashboard allows users to explore agricultural performance by:
- State
- Year
- Crop Type
- Season

### 4. Data Analysis
The project supports analysis of:
- Crop production trends over time.
- Cultivated area and agricultural productivity.
- Crop-wise and state-wise performance.
- Seasonal variations in crop production.
- Regional differences in agricultural output.

## Key Learnings
- Data cleaning and transformation using Excel.
- Summarizing data with formulas and Pivot Tables.
- Data modeling and DAX calculations in Power BI.
- Creating interactive dashboards and KPI cards.
- Turning raw agricultural data into meaningful insights.

## Project Outcome
Successfully developed an agricultural data analysis workflow using Excel and Power BI to organize data, analyze crop production patterns, compare regional performance, and present insights through interactive visualizations.
